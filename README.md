# Windows 11 Coworking Station Deployment

Комплекс скриптов для быстрой автоматической подготовки рабочих станций коворкинга на Windows 11 Pro/Enterprise.

### Реализованный функционал
- **Единое именование**: Автоматически соблюдается равенство `Имя ПК = Имя пользователя = Сетевая папка`.
- **Файловый обмен**: Создание папки `C:\Shares\<ComputerName>`, выдача SMB-доступа и генерация ярлыка на рабочем столе.
- **Поддержка Veyon**: Автозапуск сервиса, открытие портов TCP `11100–11400` в брандмауэре и приоритетные правила запуска.
- **Безопасность USB**: Запрет исполнения файлов (`EXE`, `BAT`, `CMD`, `MSI`) со съемных дисков на уровне реестра и AppLocker при сохранении возможности чтения документов (PDF, Office). Отключен AutoRun/AutoPlay.
- **Защита оболочки**: Отключение диспетчера задач, панели управления, меню «Выполнить» (`Win+R`) и скрытие диска `C:\`.
- **Сброс сессии**: Скрипт `Reset-Session.ps1` для мгновенной очистки кэша и пользовательских загрузок перед следующим клиентом.

### Развертывание
1. Склонируйте репозиторий на рабочую станцию или скопируйте архив с файлами.
2. Откройте консоль **PowerShell от имени Администратора**.
3. Выполните:
